Android Modules Repository

zamr

Eine kuratierte Sammlung von Root-Modulen für Magisk, KernelSU, APatch und MMRL. Der Index wird automatisch aus den neuesten GitHub-Releases aktualisiert.

MMRL-Repository Quellcode auf GitHub Modulindex (JSON)

Installation in MMRL

In MMRL unter „Repositories“ hinzufügen:

https://zelect0r.github.io/zamr/

Automatische Updates

Der Updater prüft alle sechs Stunden die neuesten Releases. Nach dem Pages-Deployment stehen neue Versionen im Index bereit.

Kompatibilität

Module sind für Android-Root-Umgebungen gedacht. Prüfe vor der Installation die Anforderungen des jeweiligen Moduls und erstelle ein Backup.
